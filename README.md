# SQL World Population Analysis

## Deskripsi
Analisis populasi dunia menggunakan SQL di Google BigQuery.
Menggabungkan 3 dataset: data negara, populasi 2020, dan prediksi populasi 2020-2050.

## Tools
- Google BigQuery (SQL)
- Dataset: countries, population_2020, population_forecast (Kaggle)

## Analisis yang dilakukan
1. Ringkasan umum populasi dunia 2020
2. Jumlah negara per benua
3. TOP 10 negara populasi terbesar 2020
4. Rata-rata populasi per benua
5. Ranking TOP 3 negara per benua (Window Function)
6. Kategorisasi negara berdasarkan populasi (CASE WHEN)
7. Tren prediksi populasi dunia 2020-2050

## Hasil Temuan
- Total populasi dunia 2020: ~7.8 miliar
- Asia mendominasi dengan populasi terbesar
- Prediksi populasi dunia akan mencapai >9 miliar pada 2040
- China dan India adalah 2 negara terpopuler di dunia
